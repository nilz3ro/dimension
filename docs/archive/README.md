# Archive

Superseded planning and design documents, kept for historical context.
Nothing in this directory describes the current system — see the root
`README.md`, `DEPLOY-GUIDE.md`, and `docs/` for that.

- `dimfix.md` — early design for the `dimension build` Dockerfile/OCI overhaul
  (largely shipped; details have drifted).
- `plan-dim-think.md` — "dumb compute launcher" architecture vision that
  informed the current POST /run + SSE design.
- `bride-agent.md` — bridge-agent pattern notes from the webhook-delivery era
  (webhook delivery has been removed; bridges consume SSE now).
- `ralph.txt` — GSD Ralph-loop automation config used during the v1.2 push.
